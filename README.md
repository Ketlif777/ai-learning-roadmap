## 学习原则

1. 每个知识点都通过代码验证。
2. 保留清楚、连续的 Git 提交历史。
3. 先理解自己写的代码，再使用 AI 改进。
4. 项目应当能够被他人复现。
5. 定期回顾并更新学习进度。
